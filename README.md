# Adventure Game (Python)

My Python learning journey, one day at a time. The best project here is **Treasure Island**, a text adventure game you play in the terminal.

## Play Treasure Island

```bash
python day-3-treasure-island/treasure_island.py
```

You start at a river crossroads and make three choices (left or right, swim or wait, then pick a door colour). One path finds the treasure. Every other choice ends in game over. When a round ends you can play again.
